Seven ownership boundaries

  • CoreAuthorizes a bounded task and coordinates durable intent.
  • HostPreserves the selected machine, workspace and native session identity.
  • BrowserFences account-scoped actions, credentials, profile and handoff.
  • TetherDelivers sanitized events and feedback within its own grant.
  • RefineryEvaluates replayable examples under separate approval.
  • ConsoleDisplays observed status; a view grants no control.
  • PlatformPins composition and qualifies distribution and rollback.

Relationship, not a credential chain

  1. Core's task grant and Host's selected identity reach Browser's command boundary.
  2. Browser keeps PinchTab actions and KasmVNC human input mutually exclusive at the current lease epoch.
  3. An OpenBao helper may resolve a scoped reference only after trusted account and origin observations.
